### こんにちは、jeremdevgit です 👋

<p><a href="README.md">English</a> · <a href="README.fr.md">Français</a> · <a href="README.es.md">Español</a> · <a href="README.de.md">Deutsch</a> · <a href="README.it.md">Italiano</a> · <a href="README.pt.md">Português</a> · <a href="README.zh.md">简体中文</a> · <b>日本語</b></p>

Windows・macOS・Linux・ブラウザー向けに、**無料・オープンソース・広告なしのソフトウェア**を作っています。テレメトリーはなく、ローカル機能にアカウントは不要。任意の同期は、あなたが選んだサービスとだけ通信します。すべてのアプリが **8 言語**に対応しています。
